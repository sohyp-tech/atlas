# Atlas Reverser
### This is a book reverse API allow you as poster:
- Signin and Post your books.
- Revirse Books and read other's books.

# 
### Technologies are used in this API:
1. <span style="background-color: darkcyan;padding: 2px; border-radius: 5px;color: #121212;">FastAPI</span> => To Make APIs And Routes.
2. <span style="background-color: beige;padding: 1px; font-size: 14px; border-radius: 5px;color: #121212;"> Pydantic </span> => Validate Data From Client.
3. <span style="background: #A78754;color: #121212;border-radius: 5px; padding: 2px;">Passlib</span> => To Hash Passwords And Secret Data From Client.
4. <span style="background: #948438;color: #121212;border-radius: 5px; padding: 2px;">SQLAlchemy</span> => To Create SQL Quries.
5. <span style="background: #a0ffff;color: #121212;border-radius: 5px; padding: 2px;">MariaDB Server</span> => To Create Server And Databases.
